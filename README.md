# 🚀 Interactive Guide to learning n8n

Welcome! This is the repository for a single-page application (SPA) designed to be a visual, and detailed guide for learning n8n from scratch.


## 💡 About This Project

This project was born from the need for an n8n guide that was interactive and visually appealing, rather than just plain text. It's a Single Page Application (SPA) built from scratch without frameworks.

## 💻 Tech Stack

* **HTML5:** For semantic structure.
* **CSS3:** For the professional design, using CSS variables, Flexbox, and a responsive layout.
* ** JavaScript:** To manage the SPA navigation interactivity, showing and hiding sections without a page reload.
